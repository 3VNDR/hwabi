# Hwabi

A MapleStory v95 server emulator written in Zig.

> **Status:** Early development. The login server is actively being implemented.

## Requirements

Before building and running Hwabi, make sure you have the following installed:

* [Zig](https://ziglang.org/) 0.16
* [PostgreSQL](https://www.postgresql.org/) 14 or newer

## Current Progress

* Networking and cryptography ✅
* Opcode dispatching ✅
* PostgreSQL integration ✅
* Login packet handling ✅
* Character creation *(in progress)*
